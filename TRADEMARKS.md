# The Scrimp name and icon

The code in this repository is covered by its licence, [LICENSE](LICENSE). The name and the icon are not.

"Scrimp", the Scrimp icon and any logo made from them belong to Mark Castle. The MIT licence gives no right to use them.

## What that means in practice

You are welcome to:

- say that your work is built on, or works with, Scrimp;
- use the name to refer to this project, in writing, talks and reviews;
- build and run Scrimp from this source for yourself, icon and all.

Please do not:

- give out a changed version under the Scrimp name or icon. If you share a fork, call it something else and use your own icon, so nobody mistakes it for this project;
- use the name or icon in a way that suggests this project made, checked or stands behind something it did not.

If you are unsure whether a use is fine, open an issue and ask.
